# Market Radar report components

This directory is reserved for deterministic export presentation components. Planned boundaries are `MarketRadarReportHeader`, `MarketRadarKeyTake`, `MarketRadarHighlights`, `MarketRadarTemperature`, `MarketRadarMoiSection`, `MarketRadarCbcSection`, `MarketRadarSources` and `MarketRadarDisclaimer`.

Components will receive `MarketRadarReportSnapshot` data and will not fetch sources, calculate metrics, inspect entitlements or mutate Free Credits. Screen UI remains unchanged in Phase 2D-1B.0.
